# North Ankole Diocese Young Girls' Health Project

A digital health initiative supporting young girls in North Ankole Diocese, Uganda, through adolescent-friendly healthcare, reproductive health education, menstrual hygiene awareness, counselling, mentorship, safeguarding, and community outreach.

## Run locally
Install Python 3.10+, then run:
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Important
This is an early-stage prototype, not a deployed clinical system. Sample data is synthetic, not real patient or field data. No field testing is claimed. Obtain organisational approvals, safeguarding procedures, and privacy/security review before any pilot involving people or sensitive information.

The dashboard is intended for aggregate indicators only. Do not upload names, phone numbers, patient identifiers, or identifiable health details.
